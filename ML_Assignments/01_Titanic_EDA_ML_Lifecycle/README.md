# Titanic Survival — EDA and ML Lifecycle Mapping
**Goal:** Explore survival patterns and map the work to a complete ML lifecycle.
## Steps
1. Load and inspect data
2. Missing-value/duplicate audit
3. Descriptive statistics
4. EDA: survival distribution, sex, passenger class, age
5. Interpret patterns
6. ML lifecycle: problem definition → data collection → cleaning → EDA → feature preparation → modeling → evaluation → deployment/monitoring
## Run
`python titanic_eda.py`
